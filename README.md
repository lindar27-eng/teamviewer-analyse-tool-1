# Analyse-Tool TeamViewer SE

Web-App zur Portfolioprüfung „Ausgestaltung digitaler Geschäftsmodelle“ (DHBW Karlsruhe, WDBM24B2, Dozent: Jonas Staib).
Das Tool stellt das Geschäftsmodell der TeamViewer SE (SDAX) dar, bewertet es und leitet Handlungsempfehlungen ab.

## Projektregeln

- Keine erfundenen Daten: jede Aussage mit Quelle und Datum.
- Fehlt ein Beleg, wird die Aussage als Annahme markiert; im Zweifel gilt die niedrigere Reifegradstufe.
- Keine vertraulichen Daten im Tool oder in Prompts.
- KI-generierter Code wird als Entwurf behandelt und vor jeder Abgabe getestet.

## Technik

- Eine einzige Datei `index.html` (HTML, CSS, JavaScript), keine Abhängigkeiten außer Google Fonts.
- Änderungen im Tool werden nur im `localStorage` des jeweiligen Browsers gespeichert. Inhalte, die alle sehen sollen, müssen in `index.html` (Objekt `DEFAULT`) eingetragen und hochgeladen werden.
